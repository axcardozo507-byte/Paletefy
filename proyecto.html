Sobre el Proyecto

Paletify es una página web creada para facilitar la selección de combinaciones de colores adecuadas para proyectos académicos, páginas web y presentaciones. El sistema genera automáticamente paletas de colores basadas en principios de armonía cromática.

Problema

Dificultad para elegir combinaciones de colores adecuadas en proyectos de diseño.

Objetivo

Generar paletas de colores de forma rápida, sencilla y visualmente equilibrada.

Beneficio

Mejorar la calidad visual de los trabajos y fortalecer el aprendizaje de la teoría del color.

Generador de Paletas

Selecciona un tipo de armonía cromática y genera una nueva paleta.

Tipos de Paletas

Monocromática

Utiliza diferentes tonos de un mismo color.

Análoga

Combina colores vecinos dentro del círculo cromático.

Complementaria

Emplea colores opuestos para crear alto contraste.

Triádica

Usa tres colores equidistantes para un equilibrio visual.
